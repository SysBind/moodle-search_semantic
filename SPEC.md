# Technical Specifcation

Semantic Search Plugin for moodle

Index content in vector database

## RAG

Prompt to LLM can be augumented with relevant content from same context, e.g: Course


## Multi-Modality
Options:
- Direct support by provider / model, same vector space for text / images / video
- Add stage to first extract text from media


  
RAG Pipelines:
pipeline stage as sub-plugins (rerank, image to text, video to text)
